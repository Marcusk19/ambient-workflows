# Ambient workflows

My custom workflows for [ambient code platform](https://github.com/ambient-code/platform). Used for testing new workflows/ideas.

## Workflows

| Workflow | Description |
|----------|-------------|
| `quay-swarm` | Multi-agent feature coordination — decomposes epics into stories and spawns parallel implementer agents |
| `quay-ticket` | Single-ticket development using a Ralph Loop tick-loop state machine |
| `quay-deploy` | Automated Quay RC deployment from Konflux FBC builds onto ephemeral OpenShift clusters with Playwright UI validation |
